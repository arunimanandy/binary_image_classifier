# MLOps Assignment 2: Cats vs Dogs Binary Image Classification

This project implements an end-to-end MLOps pipeline for a pet adoption platform use case: binary image classification of cats and dogs.

## What is included

- Data download, preprocessing, augmentation-ready dataloaders, and train/validation/test split.
- Git and DVC-ready project layout for code and data versioning.
- Baseline PyTorch CNN model training with MLflow experiment tracking.
- Serialized model artifact format: `models/catdog_cnn.pt` generated by training.
- FastAPI REST inference service with `/health`, `/predict`, `/metrics`, and request logging.
- Unit tests using pytest for preprocessing and inference utility functions.
- Dockerfile and Docker Compose deployment target.
- GitHub Actions CI pipeline to install dependencies, test, and build Docker image.
- GitHub Actions CD pipeline to publish image and deploy through Docker Compose on a self-hosted runner or VM.
- Kubernetes manifests are included as optional deployment artifacts.
- Smoke test script for post-deployment health and prediction verification.

## Important dataset note

The assignment requires the Kaggle Cats and Dogs classification dataset. This repository does not embed Kaggle data or credentials. Use the included scripts after configuring Kaggle API credentials. The workflow downloads, preprocesses, splits, trains, tracks experiments, builds the service, and deploys it reproducibly.

## Quick start

### 1. Create environment

```bash
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### 2. Configure Kaggle credentials

Create `~/.kaggle/kaggle.json` from your Kaggle account API token and restrict permissions:

```bash
mkdir -p ~/.kaggle
cp /path/to/kaggle.json ~/.kaggle/kaggle.json
chmod 600 ~/.kaggle/kaggle.json
```

### 3. Download dataset

```bash
bash scripts/download_data.sh
```

Expected raw layout after download/extraction:

```text
data/raw/
  Cat/
  Dog/
```

If the extracted folder names differ, update `configs.yaml` values `data.cat_dir` and `data.dog_dir`.

### 4. Preprocess and split data

```bash
python -m src.data.preprocess --config configs.yaml
```

This converts images to 224x224 RGB and creates:

```text
data/processed/train/cat
 data/processed/train/dog
 data/processed/val/cat
 data/processed/val/dog
 data/processed/test/cat
 data/processed/test/dog
```

### 5. Track data with DVC

```bash
dvc init
dvc add data/raw data/processed
git add data/raw.dvc data/processed.dvc .gitignore dvc.yaml params.yaml
git commit -m "Add DVC tracked data"
```

Optional remote:

```bash
dvc remote add -d storage /path/to/dvc-remote
dvc push
```

### 6. Train model with MLflow tracking

```bash
mlflow ui --host 0.0.0.0 --port 5000 &
python -m src.ml.train --config configs.yaml
```

Output artifacts:

```text
models/catdog_cnn.pt
reports/confusion_matrix.png
reports/loss_curve.png
mlruns/
```

### 7. Run tests

```bash
pytest -q
```

### 8. Run API locally

```bash
uvicorn src.api.main:app --host 0.0.0.0 --port 8000
```

Health check:

```bash
curl http://localhost:8000/health
```

Prediction:

```bash
curl -X POST http://localhost:8000/predict \
  -F "file=@data/processed/test/cat/<image-name>.jpg"
```

### 9. Build and run Docker image

```bash
docker build -t catdog-mlops:local .
docker run --rm -p 8000:8000 catdog-mlops:local
```

### 10. Deploy with Docker Compose

```bash
cd deployment/docker-compose
docker compose up -d
cd ../..
python scripts/smoke_test.py --url http://localhost:8000 --image data/processed/test/cat/<image-name>.jpg
```
